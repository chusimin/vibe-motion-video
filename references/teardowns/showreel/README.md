## 两个风格簇(收敛)
- **editorial-saas(ObiN/Varchasva)** → 已建风格包。亮暖底 + 巨型切边粗体 + 逐词强调 + 设备框 UI + 大量留白,紫主绿火花,暗场/满色帧做重音。**克制、editorial、产品向。**
- **eclectic-agency(Bohdan)** → 待建。3D 等距场景、实拍 b-roll、光爆/能量转场、fintech dashboard 演示(OPEN ACCOUNT + 光标)、数据地图、口播+kinetic 字幕。**更满、更能量。**

## 跨片提炼的高级原理(进 motion-constitution / showreel Playbook)
1. **能量曲线**:开场记忆点 → 慢留铺陈 → 产品落地 → 高潮快切 0.6-1.2s → 干净落版。
2. **对比节拍**:亮 → 暗 → 满色 交替,纯色帧当重音。
3. **巨型排版出血 + 负字距**:分量来自 typography。
4. **逐词强调**:整句中性,唯一关键词换色/斜体,一帧一个焦点。
5. **真实 UI 进设备框/3D 透视**:产品有体积、可信。
6. **留白换气**:极简单元素帧。
7. **强调色只给焦点 + 设计过的转场**(mask wipe / 光爆 / 色差)。

# Showreel 导演手册（方法论提炼）

> 把一条 showreel 从「能看」做到「能发、有高级感」的打法。PLAYBOOK.md 讲**流程怎么跑**,本文讲**怎么做得好看**。
> 做 showreel(尤其产品片)时,概念/分镜阶段(③④)和渲染自审阶段(⑥⑦)都应对照本文。
> 原始实战提示词见 [../references/showreel-director-prompt.md](../references/showreel-director-prompt.md)。

## 1. 情绪曲线:痛 → 转 → 爽 → 燃
别平铺直叙堆功能。一条好片有情绪起伏:先**痛**(戳中现状),再**转**(产品登场),然后**爽**(看它怎么解决),最后**燃**(规模化/效果放大到高潮)。分镜的 `purpose` 要服务这条曲线。

**60s 英雄结构(实战验证,已编进 `presets/structures/showreel.json` 的 heroMode60s):**
| 段 | 时长 | 干的事 |
|---|---|---|
| Hook | 3-4s | 别划走的理由:痛点 or 最惊艳成品,3 秒抓人 |
| 登场 | ~8s | 痛点 → 产品登场,情绪从痛转到期待 |
| **工作流演示** | **~22s** | **★重头戏**:把产品**怎么用**一步步演给人看(真实页面/录屏优先) |
| 规模化 payoff | ~12s | 爽点放大:批量/效果/规模感,把「爽」推到「燃」 |
| CTA | ~12s | 收尾召唤 + 品牌定格 |

短片按比例缩:15s≈hook+1功能+cta;30s≈hook+痛点+登场+2-3功能+payoff+cta。**工作流演示永远是重头戏,别为了塞功能把它压没。**

## 2. 反 Slop 清单（渲染后逐条自检,对标 linear.app 水准）
渲完抽 8 张关键帧,对照下面逐条过,改掉每一条「廉价感」来源:
- [ ] **不许 emoji 当图标** —— 用 SVG / 几何图形。
- [ ] **不许俗气渐变** —— 拒绝彩虹/紫粉糖水渐变;渐变要克制、低饱和、贴品牌。
- [ ] **不许霓虹乱发光** —— glow/外发光会廉价,慎用或不用。
- [ ] **不许 AI 模板风** —— 居中大标题+副标+三卡片的套路化排版,要打破。
- [ ] **严格只用产品真实色板** —— 颜色全部取自阶段0 提取的 token,不另发明。
- [ ] **标题够大够紧** —— 字号敢放大,字距收紧(负字距 letter-spacing),分量感来自 typography。
- [ ] **前 3 秒必须抓人** —— hook 不行就重做,别指望后面救。
- [ ] **关键信息上字幕** —— 80% 的人静音看,重点文字必须在画面里(本 skill 的卡拉OK字幕已覆盖)。
- [ ] **动效有缓动** —— 用 spring/贝塞尔,不要线性匀速;入场错峰(stagger)别齐刷刷。
- [ ] **留白与对齐** —— 元素别挤,网格对齐,呼吸感。

## 3. 审美心法
- **分层迭代**:先搭画面 → 再调样式 → 再加动效 → 最后加品牌。别一次把所有要求倒给 Agent,一层一层来。
- **先给图,少给指令**:每个阶段先渲出 MP4 / 用 `remotion still` 导关键帧给人看,用画面对齐审美,而不是用文字描述。
- **审美由人把关**:Agent 能把它做到 80 分,最后 20 分的高级感靠真人挑刺迭代。所以**每个阶段都停下来给图确认**。
- **音乐后期叠**:先渲无声 / ProRes,再进剪映等工具对鼓点配乐。别在 Remotion 里硬怼音乐。

## 4. 分阶段闸门纪律（导演模式)
严格分阶段、每阶段产物 + 停下等「继续」,不许跳步、不许自动连跑。尤其:
- **吃透产品先行**:动手前先扫代码/资料,提炼真实**视觉 token / 文案 / 素材 / 核心工作流 / 产品定位**,并确认整片节奏风格基调。
- **组件库优先**:正式建全片前,先建 `theme`(色板/缓动)+ 可复用组件(逐词遮罩标题、磁吸按钮、标签、卡片),并做一个 **5s 概念小样**渲出来确认好看,再铺全片。这一步别跳——它决定全片质感的一致性。
- **逐段做逐段看**:一个镜头 = 一个 Sequence;每 ~15s 一个独立片段,逐段渲、逐段确认(与本 skill 的 15s 分段渲染天然契合)。

## 5. 只用真货（铁律）
颜色、文案、卖点原话、图片/logo、核心工作流——**全部取自真实产品**,禁止编造占位内容。拿不到就停下来问,不要瞎猜填充。这是「能直接发」与「demo 感」的分水岭。

## 6. 环境/联网兜底（Claude Code & Codex 通用)
- 操作被沙箱拦截、或需要联网/审批授权(Codex 常见)→ **先停下告诉用户,别静默跳过**。
- 要抓的参考链接 / 要装的 Remotion 知识包打不开 → 降级:读 `remotion.dev/docs` 与 `remotion.dev/llms.txt`,或凭已有 Remotion 知识做,拿不准就问。
- 加载 Remotion 知识:Claude Code 可试 `npx skills add remotion-dev/skills`;装不上就降级,别卡死。

## 7. 两种模式怎么选
- **CLI 流水线(PLAYBOOK.md 8 步)**:要自动化、要多产出类型、要可复现/断点续跑、批量产片 → 走这条。本手册的情绪曲线/反 slop 清单/真货纪律作为质量准绳叠加其上。
- **导演模式(references/showreel-director-prompt.md)**:就做一条 hero 片、要最高完成度、愿意逐阶段陪跑确认 → 走这条,Agent 直接写 bespoke Remotion 代码。
两者可混用:导演模式里也能调用本 skill 的 `voice synth`(配音+字幕)、`render`(分段渲染)、`assemble`(响度归一)等 CLI 能力。

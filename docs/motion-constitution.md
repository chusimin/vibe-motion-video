# 动效宪法(Layer 0 · 通用手艺,全类型共享)

> 决定 80% 高级感的、与类型无关的底层手艺。任何类型的片都要过这一层;类型 Playbook 只写各自独有的部分,不重复这里。
> 这是「为什么不好看」的根治清单——AI/模板片普遍栽在这几条。

## 七条核心原则
1. **物理缓动**:用 spring(带 overshoot/settle),不用线性/默认 ease。动效要有重量。统一一套缓动语言。
2. **错峰编排(stagger)**:元素不要同时出现;主元素先,支撑元素跟,级联出场引导视线。
3. **狠层级**:一帧一个焦点。字号比例要夸张(巨大标题 + 极小标签),不要什么都"中等大小"。
4. **克制**:一个时刻只做一件事。拒绝"全程乱动 + 渐变 + 发光 + 多色"。少即贵。
5. **节奏呼吸**:留停留时间让人读;剪辑有节拍(尽量卡音乐);不要匀速也不要永不停。
6. **颜色纪律**:1 底色 + 1-2 中性 + 1 强调色(只在高潮/CTA 当火花用)。拒绝彩虹/糖水渐变。
7. **声画锁定**:剪辑点和强调动作落在鼓点上;动效accent 与音频同步。

## 排版与连续性
- 大标题**收紧字距**(负 letter-spacing),真字体配对,光学对齐。
- 全片共享设计 token 与动效语言 → 像「一部片」,不像拼模板。
- 转场要设计(共享元素 morph、匹配剪辑),不是一律淡入淡出。

## 反 Slop 清单(渲染后抽 8 帧逐条过)
- [ ] 不许 emoji 当图标 → 用 SVG
- [ ] 不许俗气渐变 / 不许霓虹乱发光
- [ ] 不许居中大标题+三卡片的 AI 模板套路
- [ ] 只用产品真实色板
- [ ] 标题够大够紧;前 3 秒抓人
- [ ] 关键信息有字幕(80% 静音观看)
- [ ] 动效有缓动 + 错峰;留白与对齐到位
- [ ] 对标 linear.app 水准

## 怎么用
- 分镜阶段(④):按宪法选动效语言。
- 渲染自审(⑥⑦):对照反 slop 清单改弱段,审美由用户把关(Agent 给 80 分,最后 20 分靠人挑刺)。
- 类型 Playbook(`docs/types/<类型>.md`)在此之上,只补类型独有的结构/节奏/招牌动效。
